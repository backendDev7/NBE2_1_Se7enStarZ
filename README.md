# sevenstars

데브코스 1차 프로젝트 7팀 `SEVENSTARZ`의 원두 쇼핑몰 클론코딩 프로젝트 입니다.

### 프로젝트 소개

```text
내가 원하는 원두를 편리하게 주문할 수 있는 `Grid & Circle`
```

현대 사회에서 없어선 안될 음료인 커피☕️ 요즘은 본인 취향에 맞는 원두를 직접 갈아서 내려먹을 정도로 원두에 대한 인기도 급상승 중입니다. 이러한 소비자들의 니즈를 충족하고자 우리는 Grid & Circle 원두 쇼핑몰을 개발합니다.


#### 주요 기능
- 원하는 원두를 장바구니에 담아 구매할 수 있는 `원두 구매 페이지`
- 새로운 원두를 게시하고 판매하는 `원두 판매자 페이지`
